### Настройка DKIM для Exchange Server.
Настройка DKIM для Exchange Server является обязательной.<br> 
Каждая организация должна настроить DKIM в дополнение к настройке SPF.<br> 
После настройки обоих протоколов необходимо добавить DMARC для завершения настройки.<br> 
Все три протокола аутентификации электронной почты (SPF/DKIM/DMARC) должны быть реализованы для каждого домена.<br>

##### Что такое DKIM?
DKIM — это метод аутентификации электронной почты, предназначенный для обнаружения поддельных адресов отправителей в электронных письмах.<br> 
Подписывая исходящие сообщения с помощью DKIM, получатели могут убедиться, что сообщение отправлено именно тем отправителем, за которого оно себя выдаёт, и что его содержимое не было изменено.

Использование DKIM для подписи исходящих писем имеет ряд преимуществ:

Получатель может проверить, что сообщение пришло от указанного отправителя.<br>
Получатель может убедиться, что содержимое сообщения (и важные заголовки, например, тема) не было изменено.<br>
Это снижает вероятность того, что электронное письмо будет идентифицировано как спам, хотя это не основная причина подписаться.<br>
Если спамер пытается использовать ваш домен или адрес электронной почты не по назначению, использование DKIM снижает вероятность проникновения спама. <br>
Многие почтовые серверы проверяют наличие действительной DKIM-подписи во входящих письмах.

Настройка DKIM для Exchange Server.<br>
В Exchange Server нет встроенной функции настройки DKIM. Поэтому вам придётся использовать сторонний инструмент на Exchange Server, который не обновляется регулярно и содержит множество ошибок.<br> 
Рекомендуемый способ — настроить DKIM для Exchange Server на стороннем спам-фильтре.

Предположим, ваш сторонний спам-фильтр не поддерживает эту функцию. Переключитесь на другой, который её поддерживает. Я рекомендую спам-фильтр SpamBull.<br> 
Он поддерживает DKIM для всех исходящих сообщений. В этой статье вы узнаете, как настроить DKIM для вашего домена в Exchange Server.

Шаг 1. Сгенерируйте сертификат DKIM.<br>
Войдите в центр администрирования SpamBull.<br>
В левом меню разверните вкладку Общие.<br>
Нажмите на Обзор доменов (см. раздел Добавить домен , если вы еще не добавили домен).<br>
Нажмите на домен, для которого вы хотите настроить DKIM.

<img width="2038" height="930" alt="image" src="https://github.com/user-attachments/assets/8d3111cd-db2d-43db-874e-0cbecc93b232" />

В левом меню панели управления доменом разверните вкладку Исходящие.<br>
Нажмите на DKIM.<br>
Выберите длину ключа DKIM (мы рекомендуем 2048, если ваш DNS ее поддерживает).<br>
Примечание: выбирайте 1024 бита только в том случае, если ваш DNS-провайдер не может использовать 2048-битный ключ.

Введите селектор DKIM: selector1.<br>
Нажмите «Сгенерировать» и сохраните новую пару «частный/публичный».<br>

Шаг 2. Добавьте запись DKIM в DNS.

После генерации ключа опубликуйте TXT-запись на авторитетном DNS-сервере вашего домена. <br>
Инструкции по этому вопросу могут различаться у разных провайдеров домена. За помощью обращайтесь к своему провайдеру.

Пример записи DKIM в публичном DNS домена:
```bash
selector1._domainkey.exoip.com
```

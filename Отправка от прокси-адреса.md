### Отправка от прокси-адреса SMTP (алиаса) в Exchange Online

Одному почтовому ящику Exchange можно назначить несколько дополнительных SMTP адресов, которые называются прокси адресами (псевдонимами или алиасами). Эти адреса позволяют пользователю получать почту, отправленную на разные SMTP адреса. При отправке писем Exchange использует только основной (первичный, primary) SMTP адрес пользователя. В Exchange Online (Microsoft 365) появилась возможность отправки писем с дополнительного SMTP адреса (алиаса), назначенного почтовому ящику пользователя.


Ранее в Exchange в качестве обходных решений для отправки с дополнительных email адресов приходилось использовать отправку от имени другого пользователя, группы или общего почтового ящика.
По умолчанию отправка от имени алиасов отключена. Чтобы включить ее:

Подключитесь к Exchange Online с помощью PowerShell модуля EXOv2: Connect-ExchangeOnline
Проверьте, разрешена ли в вашем тенанте Microsoft 365 отправка от имени алиасов: Get-OrganizationConfig| ft SendFromAliasEnabledGet-OrganizationConfig SendFromAliasEnabled
В данном примере SendFromAliasEnabled =False . Чтобы разрешить использование прокси адресов для отправки, выполните: Set-OrganizationConfig -SendFromAliasEnabled $True
Также вы можете включить эту опцию через Exchange Admin Center -> Settings -> Mail flow -> Turn on sending from aliases.Включить опцию "Turn on sending from aliases"
Теперь вы можете воспользоваться Outlook, или Outlook for web для отправки письма с альтернативных SMTP адресов пользователей.
Добавьте пользователю дополнительный SMTP алиас через EAC ( Mailboxes -> выберите пользователя -> Email addresses -> Manage Email Address types -> добавьте дополнительный SMTP адрес)назначить smtp адиас для почтового ящика exchnage onlineили с помощью PowerShell:

Set-Mailbox "maxtest" -EmailAddresses @{add="maxalias@winitpro.onmicrosoft.com"}

Список всех адресов, назначенных на ящик пользователя можно вывести так:

Get-Mailbox maxtest | fl EmailAddresses, PrimarySmtpAddress

Get-Mailbox - вывести список email адресов, назначенный почтовому ящику

Теперь вы можете отправить письмо с любого из дополнительных SMTP адресов.

Если вы используете Outlook for web, нужно открыть настройки ящика (Settings -> Mail –> Compose and reply). Найдите секцию Addresses to send from. Здесь нужно выбрать дополнительные SMTP адреса, которые будут доступны в поле From при отправке.

Отметьте те из назначенных алиасов, которые вы хотите использовать.

Создайте новое письмо и в меню включите опцию Show From, чтобы при отправке можно было выбрать от имени какого адреса вы хотите отправить письмо.

показать кнопку отправку от имени

Щелкните по полую From, выберите нужный SMTP адрес и отправьте email.

отправка от имени алиаса в outlook

При отслеживании отправки такого письма в логах Exchange Online оно будет отображаться с алиасом в поле Sender.

В Exchange Online вы можете использовать плюс-адреса для доставки почты, но не для отправки.
Функция отправки от имени алиасов работает только для почтовых ящиков в Exchange Online и не доступна для on-premises Exchange Server.
